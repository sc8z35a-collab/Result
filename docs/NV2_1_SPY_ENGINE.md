# NV2.1 Spy Engine · 人間的照準モデル · 高精細16関節造形 設計書

## 1. 概要
本アップデートでは、Harbor Range の戦術体験とキャラクター品質を次の4本柱で大幅に刷新しました。

1. **3対3専用 味方NPC強化（NV2 → NV2.1 選択）**
   - ロビー（`#lobby`）で **3対3** を選択したときのみ専用セレクタ `#allyAiWrap` が表示され、味方NPC 2体（`NAGI [D1]` / `KAI [MS10]`）のどちらか1体を **NV2.1** へアップグレード可能（標準 `NV2 × 2` も選択可）。
   - `1v2` / `1v1` では自動的に非表示となり、試合ロジック側（`Match`）でも `mode === '3v3'` のときのみ有効化されます。
2. **NV2.1 + スパイエンジン（Spy Engine）**
   - **完全フェアプレイ（目視限定・ウォールハックゼロ）**: 直接視線（`obstruction(eye, tp) > 1`）かつ視野内で目視した敵だけをビジュアルドシエ（位置・速度・視線方向・装備・残HP・リロード状態・履歴）へ記録。
   - **目視情報からの行動予測**: `HOLDING_ANGLE` / `DUELING_ALLY` / `TANKER_ROTATE` / `RETREAT_HEAL` / `PUSHING_LANE` の意図を推定し、将来の到達座標・視線コーン・背後死角（110°〜180°のリアブラインドスポット）を算出。
   - **4状態ステルス裏どりステートマシン**:
     - `SPY_RECON`（視認偵察）: 外周レーンの遮蔽経由で敵配置と視線方向を目視把握。
     - `SPY_INFILTRATE`（潜入裏どり中）: 予測した敵の視線コーン内グリッドへ高コストペナルティを課すステルス A*（`buildSpyStealthWeights`）でコンテナ裏を回り込み、背後死角ノードへ潜入。遠距離で気づかれていない間は射撃を控えるトリガーディシプリン（`holdFire`）を発動。
     - `SPY_STRIKE`（裏どり急襲）: 背後・死角射程に入ったら一気に急襲し、相手の振り返り方向と逆へ回り込みながら撃破。
     - `SPY_VANISH`（離脱・再潜伏）: 撃破後・低HP・弾薬低下・挟撃検知時に遮蔽裏へ即離脱して再潜伏。
   - **超高速反応 & 360Hz 多弾同時＋照準線予見回避（`computeSpyDodge`）**:
     - NV2 より大幅に速い知覚・姿勢更新周期（`28ms / 38ms`）と反応速度（`90–122ms`）。
     - 44m以内・0.42秒以内の複数飛翔弾を同時評価し、さらに視認中の敵が自分へ銃口を向けた瞬間（`aimDot > 0.945`）も予見回避。
     - 6方向の回避候補すべてを `walkable()` で2段階判定し、壁詰まりを避けつつ全飛翔弾からの最小クリアランスと遮蔽接近を最大化。高弾道には即座のしゃがみ回避（`DUCK`）、近距離低弾道には回避ホップ（`HOP`）を使い分けます。
3. **全NV共通「人間的ニューロモーター照準コントローラ（`HumanAimController`）」**
   - 従来の「12.2 rad/s 即時追従＋2次加速度先読み＋極小ジッター」によるオートエイム感を撤廃し、**NV2 / NV2.1 を含む全NPC**へ物理的人間照準を導入。
   - **視覚反応遅延リングバッファ**: 実時間より `165–225ms`（NV2） / `90–122ms`（NV2.1）前の視認状態を参照するため、プレイヤーの急な切り返し・ジャンプ・しゃがみに対して照準が自然に遅れて外れます。
   - **初回視認捕捉ディレイ（Acquisition Latency）**: 敵を視認・ターゲット切替してから引き金を引くまでに人間的な反応時間が必要。
   - **2次バネ・ダンパー手首追従（PD制御＋角速度上限）**: フリック時の自然なオーバーシュートと収束を再現。
   - **時間連続な人間エイム揺らぎ（呼吸＋手首ドリフト）**: ランダムな1発ごとの拡散ではなく滑らかに揺らぐため、弾道が自然な近弾・かすり弾になります。敵の横移動角速度・急反転・自身の走行/跳躍・距離でリアルに拡大。
   - **連射リコイル上昇・バーストブルーム・被弾/至近通過弾フリンチ**: 撃ち続けや被弾・至近弾（`<2.25m`）で照準が物理的にブレるため、プレイヤーの先制射撃や制圧射撃が有効になります。
4. **16関節キャラクターのディティール・造形・作り込みの大幅向上**
   - [`dist/js/geometry.js`](../dist/js/geometry.js) に5種の高精細スカルプトプリミティブを追加:
     - `bevelBox`: 解析法線付き26面体面取り装甲プレート
     - `sculptLimb`: 楕円断面マルチリング・アナトミカルロフト（大腿・ふくらはぎ・上腕・前腕・体幹）
     - `ribbedJoint`: 蛇腹状ラバー製フレックスガスケット（股・膝・足首・腰・首・肩・肘・手首）
     - `hingeRotor`: 機械式関節ドラム＋突き出しステンレスピボットピン
     - `curvedPlate`: 曲面ラップアラウンド装甲シェル（肩ポールドロン・前腕ブレーサー・脛グリーブ・膝蓋装甲）
   - [`dist/js/models.js`](../dist/js/models.js) の全16ボーンを高精細造形へ全面刷新し、さらに **NV2.1 専用スパイバリエーション**（ミッドナイトカーボン装甲・発光エメラルドシアン3眼NVG・肩シェブロン発光・背部ステルスフィン）を搭載。
   - [`dist/js/rig.js`](../dist/js/rig.js) の膝（Shin ボーン）に **半角バイセクター膝蓋骨（パテラ）追従** を追加し、深いしゃがみ・スプリント時も膝当てが関節中央に自然追従します。
