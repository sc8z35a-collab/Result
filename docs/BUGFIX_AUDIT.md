# Result の不具合修正一覧

`main` のコミット `7fc740a` を基準に、80件を重大度順に記録しました。同じ80項目の回帰テストを修正前後で実行し、修正前は80件が失敗、修正後は80件が成功しました。IDは `tools/regressions.test.mjs` と `tools/ui-regressions.test.mjs` のケース先頭に対応しています。

## P0 致命的 — 起動・描画の停止

| ID | 症状 | 修正 |
| --- | --- | --- |
| 01 | ゲームパッドへのアクセスを拒否するiframeで、毎フレーム例外が発生して試合が進まない | 権限エラーを処理し、ほかの入力と対戦の更新を続ける |
| 02 | 試合中にWebGLコンテキストが失われると、画面が描画されなくなる | 試合を一時停止し、同じ得点・装備・弾数のまま互換描画へ切り替える |
| 03 | 小さいFP16バッファの確認に通っても、実解像度の割り当てに失敗すると描画が止まる | 実寸でバッファ一式を検証し、失敗時はRGBA8に切り替える |
| 04 | 壊れた保存設定に無効な解像度や武器名があるとロビーや試合を開けない | 保存値を検証し、有効な初期値で復元する |
